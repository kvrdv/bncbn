UX/UI
дизайн

Figma Affinity Adobe

Обычно работаю с готовыми макетами и не занимаюсь дизайном самостоятельно. Когда нужно протестировать элемент интерфейса или создать прототип, использую Figma - основной инструмент для дизайна. С PSD макетами работаю в Affinity или использую продукты Adobe.

Веб
разработка

HTML CSS JavaScript

В стек технологий входит: HTML, препроцессоры CSS (БЭМ), JavaScript, Node.js, cборщики пакетов Parcel и Webpack, CI-сервисы Travis и AppVeyor, система контроля версий GitHub. Применяю компонетный подход, пишу симантически корреткный, валидный и адаптивный код.

Проектное
управление

Notion Telegram Zoom

Руководил проектами по внедрению систем SSO, распознавания лиц, контроля доступа и видеонаблюдения, интеграции продуктов Oracle и IBM. Работал с Project, Trello, Slack. Основной инструмент для контроля задач - Notion, для коммуникации использую Telegram и Zoom.
