Design

We work with ready-made layouts or design by ourselves. When we need to test an interface element or create a prototype, we use Figma, which is the main design tool for us. Also we work with Affinity and Adobe mockups.

Figma Affinity Adobe SketchUp FL Studio

Development

Our technology stack includes: HTML, CSS preprocessors, JavaScript, Node.js, package builders Parcel and Webpack, CI services Travis and AppVeyor, version control system GitHub and more. We use a component approach, write simantically correct, valid and adaptive code.

TypeScript React Node.js Docker SQL MongoDB

Management

We led projects of implementing SSO, facial recognition, access control and video surveillance systems, integration of Oracle and IBM products. We worked with Microsoft Project, Atlassian, Slack and more. Our main tool for task control is Notion, and for communication we use Telegram and Discord.
